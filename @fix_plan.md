# Mission: Operation Fibonacci

The goal is to create a Python script that calculates the Fibonacci sequence and verifies it works.

- [ ] Create a Python script `fib_gen.py` that:
    - Calculates the first 20 Fibonacci numbers.
    - Prints them to the console.
    - Saves them to a file named `results/fibonacci.txt`.
- [ ] Run the script to verify it works.
- [ ] Check if `results/fibonacci.txt` exists.
